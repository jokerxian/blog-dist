一管羊毫 ​

笔挂在笔架上，笔尖朝下，像一滴将落未落的墨。

羊毫是软的。软到什么程度：蘸饱了墨，把笔提起来，笔尖会自己弯下去，弯成一道弧，像被水的重量压着。狼毫不这样。狼毫有脾气，提起来是直的，落下去有回弹。羊毫几乎没有脾气，它把力气全交给握笔的人——你松一分，它就软一分；你急，它也跟着散。

一、提按 ​

按下去，笔毫铺开，一笔可以写得很宽；提起来，毫尖收拢，细得像一根丝。中间的过程不是开关，是连续的：从按到提，力在指间一点一点放掉。所以同一笔横，起笔按、行笔略提、收笔再按，纸上便留下一段由粗到细、再由细到粗的痕迹。痕迹不会说谎，哪一瞬犹豫，哪一瞬用力过猛，都留在纸上。

中锋是让笔尖走在笔画中间，墨从两侧均匀洇开，线条圆而厚。侧锋把笔尖偏到一边，出来的线一面光、一面毛，有刀意。羊毫做中锋难，因为软，稍不留神就趴下去，成了偏锋；也正因为难，练出来的线才有厚度。硬笔写字只有一个力度，毛笔写字有无数个力度，差别就在这无数个中间态里。

执笔不必太紧。指实掌虚，腕要松，松到笔能在指间微微转动。写小字用指，稍大用腕，再大就要悬肘，整条手臂悬在空中，靠肩背的力送出去。悬肘写字，起初手会抖，抖得厉害；抖过那一阵，笔反而稳了。

一点成一字之规，一字乃终篇之准。

——孙过庭《书谱》

第一点落下去，整幅字的调子就定了。这一点重，后面都得撑得住；这一点轻，后面就不能忽然压下去。写文章的第一句、做版式的第一屏，也是这个道理。开头不必漂亮，但要定得住。

二、墨分五色 ​

古人说墨分五色：焦、浓、重、淡、清。这不是五种墨，是一种墨加五种水。

蘸墨之后不洗笔，直接去蘸水，笔根的水往上走，笔尖的墨往下沉，笔肚里自然分出层次。一笔下去，先重后淡，中间没有接缝，这叫“一笔墨”。会用它的人，一支笔能写出一整片山水的远近。

水多则淡，水少则焦。焦墨干涩，用来提神，一两处便够；浓墨饱满，可作正文；重墨居中，隔开一层；淡墨化得开，宜作远景；清墨几乎透明，只留一点意思。分寸在于克制：焦墨用多了，画面就浊；淡墨用多了，画面就飘。一张纸上的黑，从来不是越多越有力。

砚边要有一只水盂。盂里的水是净的，砚池里的水是浑的，两下不能混。初学的人常犯一个错：嫌墨淡了，直接往砚池里添水，越添越浑，墨色发灰，像隔了一层脏玻璃。

三、从宣纸到屏幕 ​

宣纸吸水，墨落下去会洇，边缘留一圈细毛，那是纤维把水引开的样子。屏幕上没有洇，只有像素，边界是硬的。这是两种材料，彼此替代不了。

但有些东西是通的：字距、行高、留白。

宣纸上写字，行与行之间留多少，是有讲究的。留窄了气闷，留宽了气散。屏幕上也一样：行高一点九，读起来松；一点四，读起来紧。古人把这叫“行气”，现在叫 line-height。字距也是，密则促，疏则断，正文里那一点点 letter-spacing，恰如落笔时的呼吸。

把纸上的分寸搬到屏幕上，最直接的办法是先把颜色和比例写成变量，让它们像砚里的墨一样，用的时候兑水，而不是每次重新磨。

ts
type InkTone = "jiao" | "nong" | "zhong" | "dan" | "qing";

interface InkColor {
  readonly name: string;
  readonly hex: string;
  readonly usage: string;
}

const inkPalette: Record<InkTone, InkColor> = {
  jiao: { name: "焦", hex: "#141414", usage: "标题与落款，一处定住全篇" },
  nong: { name: "浓", hex: "#2B2B2B", usage: "正文，墨足而不滞" },
  zhong: { name: "重", hex: "#4A4A4A", usage: "引文与注释，退后半步" },
  dan: { name: "淡", hex: "#8A8A8A", usage: "分隔线与次要信息" },
  qing: { name: "清", hex: "#D8D4CC", usage: "纸底与留白，不与人争" },
};

interface TypeMetrics {
  readonly fontSize: number;
  readonly lineHeightRatio: number;
  readonly trackingRatio: number;
}

const proseMetrics: TypeMetrics = {
  fontSize: 17,
  lineHeightRatio: 1.9,
  trackingRatio: 0.02,
};

function toCss(metrics: TypeMetrics): Record<string, string> {
  const { fontSize, lineHeightRatio, trackingRatio } = metrics;
  return {
    fontSize: `${fontSize}px`,
    lineHeight: String(lineHeightRatio),
    letterSpacing: `${(fontSize * trackingRatio).toFixed(2)}px`,
  };
}

const inkStyles = Object.fromEntries(
  (Object.keys(inkPalette) as InkTone[]).map((tone) => [
    `--ink-${tone}`,
    inkPalette[tone].hex,
  ]),
);

export { inkPalette, proseMetrics, toCss, inkStyles };
export type { InkTone, InkColor, TypeMetrics };

这段代码没有什么技巧，只是把“焦浓重淡清”五个字换成了五个十六进制值，把行气换成一个小数。换过去之后，纸上的分寸还在，只是不再需要研墨。

也有搬不过去的东西。宣纸记得你落笔的速度，屏幕只记得你最后保存的那一版。所以这些年我仍隔几日写一次字，不为练，只为让手记得分寸。

四、分寸 ​

写坏一张纸，多半不是因为不会写，而是因为不肯停。笔已经干了，还想再拖一笔；墨已经够了，还想再压一层。工具越好，越容易这样。屏幕上是 undo，纸上是重来，成本不同，分寸却同源：知道在哪里收住。

笔洗了，挂回笔架，笔尖朝下。水顺着毫毛往下滴，滴在砚池里，很轻的一声。
