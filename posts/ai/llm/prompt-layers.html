写好 Prompt 的四个层次 ​

同一件事，换一种问法，模型的输出可能天差地别。Prompt 的进步，通常发生在结构上。

一、第一层：说清任务 ​

最基础的 Prompt 只回答三个问题：做什么、给谁做、输出成什么格式。

text
你是资深后端工程师。
请把下面这段 Java 代码改写成使用 try-with-resources 的版本，
保留原有注释，并说明修改理由。

二、第二层：给上下文 ​

角色、约束、示例 ​

  • 角色决定语气与知识边界；
  • 约束排除不想要的答案；
  • 示例比形容词更有效。
text
输出要求：
1. 只输出修改后的代码；
2. 代码块语言标记为 java；
3. 不要解释。

三、第三层：拆步骤 ​

复杂任务不要指望一次生成。先列提纲，再逐段展开，最后统一润色。每一步都可以单独校验。

让模型自我检查 ​

在最后加一句「先检查是否满足以上约束，再输出」，可以明显减少格式跑偏。

四、第四层：变成工作流 ​

当一段 Prompt 被反复使用，就该把它沉淀成模板：变量抽出来，步骤固定下来，接上脚本或 Agent。

Prompt 的上限，往往不是模型的能力，而是写 Prompt 的人对任务本身的理解。
