Nginx 编译安装与静态站点配置 ​

用包管理器装 Nginx 最省事，但有些环境里需要自己指定编译参数、模块和安装路径。这篇记录一次源码编译安装的完整流程，以及装完之后最基本的配置。

一、下载安装包 ​

到 Nginx 官方下载页 选择需要的版本，下载 tar.gz 源码包。

二、解压与编译安装 ​

先建好安装目录，再安装编译依赖：

bash
# 创建安装目录
mkdir -p /usr/local/nginx

# 下载 Nginx 所需依赖
yum install -y gcc-c++ zlib zlib-devel openssl openssl-devel pcre pcre-devel

把下载好的源码包放进 /usr/local/nginx，然后解压、编译：

bash
# 进入目录并解压
cd /usr/local/nginx
tar -zxvf nginx-1.24.0.tar.gz

# 进入源码目录
cd nginx-1.24.0

# 配置，--prefix 指定安装路径
./configure --prefix=/usr/local/nginx

# 编译并安装
make && make install

# 查看安装位置
whereis nginx

--prefix 决定了最终的目录结构：可执行文件在 sbin/，配置在 conf/，静态文件默认放在 html/。安装完成后访问服务器 IP，能看到默认欢迎页就说明成功了。

三、启停命令 ​

Nginx 的命令都在 sbin 目录下，先切过去再操作：

bash
cd /usr/local/nginx/sbin/

./nginx              # 启动
./nginx -s stop      # 强制停止
./nginx -s quit      # 等待请求处理完后退出
./nginx -s reload    # 重新加载配置
./nginx -s reopen    # 重新打开日志文件

改完配置推荐用 reload 而不是 stop，前者不会中断正在处理的连接。

四、配置一个静态站点 ​

把前端打包产物（例如 dist）上传到服务器，然后在 server 块里指向它：

nginx
server {
    listen       80;
    server_name  localhost;

    location / {
        root   /usr/local/web/dist;   # dist 文件目录
        index  index.html index.htm;

        # 如果用的是 history 路由，需要开启此项
        # try_files $uri $uri/ /index.html;
    }
}

改完执行 ./nginx -s reload 生效。

如果前端项目用的是 Vue Router 或 React Router 的 history 模式，一定要打开 try_files，否则刷新子路由会返回 404。

五、小结 ​

源码安装并不复杂，关键在于依赖齐全与 --prefix 路径统一。配置改动后先 nginx -t 检查语法，再 reload，能避免大部分意外。
