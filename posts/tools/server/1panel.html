1Panel 面板安装与初体验 ​

命令行用久了，总有些操作更适合交给图形界面：看磁盘 IO、翻日志、管容器、传文件。1Panel 是这类需求里比较轻的一个选择，开源、基于容器、安装也简单。

一、1Panel 是什么 ​

1Panel 是一个现代化、开源的 Linux 服务器运维管理面板。它把常用的主机管理能力收进一个 Web 界面，同时把应用安装交给容器来做。

它的几个特点：

  • 高效管理：通过 Web 图形界面管理主机监控、文件、数据库与容器；
  • 快速建站：深度集成 WordPress、Halo 等开源建站程序，域名绑定与 SSL 证书配置一键完成；
  • 应用商店：精选上架各类开源工具，安装与升级都在面板内完成；
  • 安全可靠：基于容器部署应用，缩小漏洞暴露面，并提供防火墙与日志审计；
  • 一键备份：支持备份到各类云端存储，恢复也只需要点几下。

二、环境说明 ​

本文是在个人测试环境里完成的实践，生产环境请按需调整防火墙与安全组策略。目标很简单：

  1. 在 Linux 系统中部署 1Panel 面板；
  2. 熟悉面板的日常使用方式；
  3. 掌握 1pctl 这个运维命令。

开始前先处理两件容易被忽略的事。

关闭防火墙或放行端口 ​

可以选择直接关闭防火墙：

bash
systemctl stop firewalld && systemctl disable firewalld

也可以只放行面板端口（下面以 10086 为例）：

bash
firewall-cmd --permanent --add-port=10086/tcp
firewall-cmd --reload

如果用的是云服务器，别忘了在安全组里同样放行这个端口。

关闭 SELinux ​

bash
sed -i 's/SELINUX=enforcing/SELINUX=disabled/' /etc/selinux/config
setenforce 0

第一条命令改的是下次开机的配置，第二条让当前会话立即生效。

三、在线安装 ​

安装目录可以自定义，默认是 /opt。先建好目录：

bash
mkdir -p /path/1Panel

然后按发行版选择对应的一键安装脚本：

bash
# Ubuntu
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && sudo bash quick_start.sh

# RedHat / CentOS
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && sh quick_start.sh

# Debian
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && bash quick_start.sh

脚本执行后会依次询问安装目录、面板端口、面板用户名与密码。端口和账号都可以自定义，也可以直接回车采用默认值。安装过程中的关键输出大致如下：

注意地址末尾那串随机字符，它是 1Panel 的安全入口，访问时不能省略。

四、首次访问 ​

浏览器打开安装输出里的地址，先看到的是初始化页面。

用刚才设置的用户名和密码登录，就能进入首页。

五、面板的日常使用 ​

服务器概览 ​

首页能看到系统状态、磁盘 IO 与进程的实时监控，适合做一次快速体检。

应用商店 ​

应用商店里可以直接安装各种开源应用，省去了自己写 compose 文件的步骤。

容器管理 ​

宿主机的容器、镜像、编排、网络、存储卷、仓库以及 Docker 基础配置，都在这里统一管理。

文件与终端 ​

文件管理提供了可视化的上传、下载与编辑；终端则可以直接在浏览器里操作服务器，临时改个配置很方便。

六、1pctl 命令行工具 ​

面板之外，1Panel 还提供了 1pctl 方便在 SSH 里操作。先看它支持哪些子命令：

bash
1pctl --help

忘记登录入口和账号时，用这条命令找回：

bash
1pctl user-info

七、小结 ​

1Panel 的上手成本很低，安装脚本把 Docker、服务注册和启动都处理好了，剩下的就是按需点选。对不想在命令行里反复查文档的人来说，它是一个顺手的补充。

更多细节可以翻阅 1Panel 官方文档。
